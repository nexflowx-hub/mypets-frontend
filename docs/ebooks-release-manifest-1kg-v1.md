## QA editorial

Cada volume desta release foi:
- diagramado em A5;
- exportado para PDF;
- renderizado página a página;
- inspecionado visualmente;
- revisto para eliminar páginas órfãs/quase vazias;
- fechado com capa, introdução, capítulos, checklist/plano prático, referências e contracapa da campanha.

## Posição editorial

Os materiais são educativos e gerais. Não substituem avaliação veterinária, comportamental ou nutricional individual.

Fontes-base editoriais usadas conforme o tema incluem:
- AAHA/AVMA preventive healthcare;
- AAHA vaccination guidance;
- AVSAB humane/reward-based training and puppy socialization;
- WSAVA nutrition guidance;
- AKC breed/lifestyle material para contextualização de perfis de raça.

## Distribuição

O master PDF deve permanecer separado do frontend.

O site pode oferecer:
1. leitura web imediata após confirmação;
2. entrega futura do PDF master por URL assinada/entitlement;
3. novas edições com novo release id e novos checksums.

Não substituir silenciosamente os PDFs desta release. Uma revisão editorial deve gerar uma nova versão.
