# API contract (v1)

Base URL: `/api/v1` (sandbox) · `https://api.mypets.lat/v1` (production)

## Conventions
- JSON only; dates ISO-8601 UTC; money as integer **cents** + ISO currency.
- Success: `{ "data": … }` (+ optional `count`, `meta.page`, `meta.total`).
- Error: `{ "error": { "code": string, "message": string } }` with proper HTTP status.
- Pagination: `?page=1&pageSize=20`; filtering: `?country=PT&kind=ANIMAL&status=ACTIVE`.
- Idempotency: `POST /contributions/intents` accepts `idempotencyKey`; replays return the
  original intent.

## Endpoints (implemented in this build)

| Method | Path | Auth | Description |
| --- | --- | --- | --- |
| GET | `/health` | — | Liveness + DB probe (`503` when DB down) |
| GET | `/stories` | public | Active stories, `?locale=pt-PT\|pt-BR\|en` |
| GET | `/impact/public` | public | Metrics; demo rows only when `SHOW_DEMO_IMPACT=true` |
| GET | `/config` | public | Brand, env, feature flags, legal entity block |
| POST | `/newsletter` | public | `{email, locale, consent}` → `201`; consent required |
| POST | `/contributions/intents` | public | `{targetType, storyId?, amountCents, currency, frequency, donor?}` → `201 PENDING` |
| POST | `/contributions/:id/confirm` | — | Mock provider verification → `PAID` (idempotent) |
| POST | `/reports` | public | `{reason, entityUrl?, email?}` → moderation queue (`OPEN`) |

## Production contract (NestJS/Fastify extraction — same shapes)

```
GET    /v1/pets                     GET    /v1/pets/:id
POST   /v1/pets                     PATCH  /v1/pets/:id
POST   /v1/pets/:id/photos          POST   /v1/pets/:id/updates
GET    /v1/protectors               GET    /v1/protectors/:id
POST   /v1/protector-applications   PATCH  /v1/protectors/:id
GET    /v1/needs   · /v1/campaigns (+ POST/PATCH)
POST   /v1/contributions/intents    GET    /v1/contributions/:id
POST   /v1/payment-webhooks/:provider
GET    /v1/me   PATCH /v1/me   GET /v1/me/impact   GET /v1/me/notifications
GET    /v1/impact/public            POST   /v1/reports
GET    /health
```

OpenAPI/Swagger is generated by the API app in development at `/api/docs`.

## Error codes
`INVALID_EMAIL`, `CONSENT_REQUIRED`, `INVALID_TARGET`, `INVALID_AMOUNT`, `INVALID_CURRENCY`,
`INVALID_FREQUENCY`, `STORY_NOT_FOUND`, `NOT_FOUND`, `ALREADY_FAILED`, `PROVIDER_REJECTED`,
`INVALID_REASON`, `INTERNAL`.
